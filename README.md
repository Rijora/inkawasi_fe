# Plantilla HTML de Ankawasi

Sitio web estático de restaurante hecho con HTML, CSS y JavaScript. No requiere PHP ni servicios de correo.

## Archivos principales

- `index.html`: página y contenido de la plantilla.
- `assets/css/`: estilos.
- `assets/js/`: interacciones visuales y navegación.
- `assets/images/`: imágenes del sitio.

## Uso

Abre `index.html` en un navegador o publica la carpeta completa en un hosting estático. Para personalizar el sitio, edita el HTML y los recursos de `assets/`.

La sección de reservas es solo visual; el botón permite llamar al restaurante por teléfono.
